# 🎯 Business Objective

The objective of this project is to analyze Steam game sales and identify patterns related to commercial performance, user preferences, and market trends through interactive data visualizations.

---

# 📂 Dataset

### Source

[View the dataset on Kaggle](https://www.kaggle.com/datasets/amanbarthwal/steam-store-data?resource=download)

### Dataset Description

The dataset includes information about games published on Steam, such as:

- Game Title
- Genre
- Publisher
- Release Date
- Units Sold
- Revenue
- Price
- User Rating
- Platform Information

### Why I chose this dataset

I selected this dataset because the video game industry generates a large amount of interesting business data. As someone interested in gaming, I found it an engaging opportunity to practice data visualization while analyzing a market I am familiar with.

---

# 🛠 Methodology

### Data Understanding

- Reviewed the dataset structure.
- Identified the main business metrics.
- Defined the key analytical questions.

### Data Preparation

- Validated data quality and consistency.
- Reviewed data types.
- Prepared the dataset for Tableau.

### Exploratory Data Analysis

Analyzed relationships between:

- Sales performance
- Game genres
- Publishers
- User ratings
- Pricing
- Revenue distribution

### Dashboard Development

Developed an interactive Tableau dashboard including:

- KPI Cards
- Sales Trends
- Genre Analysis
- Publisher Performance
- Revenue Breakdown
- Interactive Filters

### Business Analysis

The dashboard enables users to identify which genres, publishers, and pricing strategies are associated with stronger commercial performance, facilitating comparisons across different market segments.

---

# 💡 Key Insights

- Certain game genres consistently generate higher sales.
- Top publishers concentrate a significant share of total revenue.
- Highly rated games tend to achieve better commercial performance.
- Pricing alone does not explain sales success.
